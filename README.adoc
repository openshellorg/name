= ns

Read-only inspection and audit of the command namespace: `ns which`, `ns conflicts` (PATH import today).

link:https://github.com/openshellorg/ns/issues[Report Bug] |
link:https://github.com/openshellorg/ns/issues[Request Feature] |
link:https://docs.opensh.org/tools/ns/index.html[Explore the docs]

== About The Project

Part of the OpenShellOrg command-namespace work: the shell finds commands in a hierarchical, task-shaped namespace instead of searching `PATH`.
Design seed: link:https://github.com/openshellorg/project-plans/blob/main/seeds/2026-10-26%20-%20namespace-inspection-audit.md[project-plans seed]. Concept page: link:https://docs.opensh.org/open-shell-org/concept-command-namespace.html[Command namespace and context requests].

Status: `which` and `conflicts` over a PATH import (v0).

== Usage

[source,shell]
----
ns                 # help
ns which git       # what 'git' resolves to, and what it shadows
ns conflicts       # every name with more than one claim (exit 1 if any)
ns --json which git
----

Today `ns` imports only `PATH` (as `legacy/...`, see NS-5). Exit codes: 0 ok, 1 not found or conflicts, 2 usage error.

Build and test with LDC + dub: `dub test`, `dub build`.
